## 3. `TouchPooler.update` (touch_adapter.py:213-346), once per env step

1. `fields = zeros(n_patches, 10)`; columns 8 and 9 (stretch) = 1.0 (:220-222).
2. Area: per patch, `n_active` = number of skin points with |force| > 1e-6 N; `area_mm2 = n_active * point_area_mm2`; `area_m2 = area_mm2 * 1e-6` (:225-236).
3. Per contact c on patch p (:266-308): `force = max(0, normal_force)`; if `force >= strongest[p]`: `contact_cols[p, 0:3] = normal_body` (world normal when absent), `[p, 3] = penetration_m * 100 / 0.1`, `[p, 4] = rel_normal_speed * 100 / 2.0`; if `other_is_self`: `self_force[p] += force`, the other body's name joins `self_parts[p]`, the pair key joins `self_pair_keys`; `normal_sum[p] += force`; `tang_sum[p] += tangential_body`; `slip_max[p] = max(slip_max[p], rel_tangent_speed * 1000)` mm/s (:293-294; the stored-position match of :300-306 runs only when `rel_tangent_speed` is None, which env.py never sends); `friction_power[p] += friction_power_w`; `_contact_first_step[(body, pair)]` set on first sight; pairs no longer seen are forgotten (:310-313).
4. `pressure = normal_sum / area_m2` (0 where area 0) Pa; `shear = |tang_sum| / area_m2` Pa; `fields[:, 0..3] = pressure, shear, slip_max, area_mm2` (:315-321); `friction_power_density = friction_power / area_m2` (:322-323).
5. Vibration (:326-330): `_hist` [n_patches, 100] rolls left by one and takes `normal_sum` as its newest column; for each patch whose history is not all zero, `fields[p, 4:8] = Goertzel.power(hist[p])` with the Goertzel of :137-176: `k = f * 100 * 0.01` (= 5, 10, 15, 20: integer bins), `omega = 2 pi k / 100`, `coeff = 2 cos(omega)`; recurrence `s = v + coeff s1 - s2` over the 100 samples oldest first; `real = s1 - s2 cos(omega)`, `imag = s2 sin(omega)`; `power = 4 (real^2 + imag^2) / 100^2` (N^2; a full-window sine of amplitude A gives A^2).
6. Self columns (:338-340): `share = self_force / normal_sum` (0 where no force); `parts = min(count of distinct own parts, 4) / 4`; `last_self = [share, parts]` float32 [n_patches, 2]. `last_contact = contact_cols` float32 [n_patches, 5] (:341). `last_fields = fields` float32 (:345).

## 7. Open points for the Swift implementation
