Explainer and dashboard: what is shown more than once

A review of the two pages as they stand on November 5, 2026: the explainer (Saved/mimo_bridge/explainer.html, built October 29, 2026, four tabs) and the development dashboard (Source/Python/mimo_bridge/tools/development_dashboard.html with its JavaScript and server, eight tabs). Each row names one thing that is presented in two or more places, where those places are, the evidence, and the one place it could live.

What each page contains (the map the rows refer to)

Explainer tabs. 1 Architecture (the model diagram with the 28-step tour, node cards, the self guide, the learning loop and weight loop diagrams, the component manifest index of 82 components, the root-cause investigations index, the repair switch cards and the "parts being worked on" list); 2 Instance inspector (one snapshot: eyes, tactile, attention maps, predicted against arrived, the command, measured wellness and curiosity, the plan, memory, self perception, the body map, named things, hierarchical self, voice head, caregiver, the gain-of-function build, and the five verdict tiles); 3 Run replay (the five verdict tiles and about 70 charts from the training stats log); 4 Probes and liveness (the gain-of-function probes for items 7 to 10 per checkpoint, and dead and locked parts of the network). Above the tabs: the run header with the training-state banner and the table of recorded repair settings. Every "what is this?" button opens one of the 89 glossary entries embedded in the page.

Dashboard tabs. Now (gain-of-function scoreboard, defects, hours per machine mode, the capability programme: ability map, hand atlas, upgrade atlas, work programme, repair history; the movement viewer; progress toward useful movement; what happens next; model health; what the bodies are doing; gain-of-function measurements); Tests (the test registry, errors, the names used on the page, root-cause investigations); Development (the developmental observer: body map, finger and hand movements, capabilities by group, first seen, discoveries, regression watch); Over time (12 gauge cards, every other gauge, segments, reviewed ability tests, the 2026-09-13 ability path, earlier lineages, experiment jobs); Video evidence; Live view; 3D viewer; Terms and definitions (85 glossary terms plus each component under its id). Above the tabs: the machine-mode strip, the "How the model works" link to the explainer, a second "Terms and definitions" button, and the Project records menu.

How this review was done

The explainer was read from its built page: the static header, the four tab sections and the JSON it embeds (data-meta, data-tour, data-doc, data-series, data-components, data-investigations) and the JavaScript that renders each tab. The dashboard was read from development_dashboard.html, development_dashboard.js, development_dashboard_terms.js, development_dashboard.py, lineage_series.py and docs/gain_of_function_v3/dashboard_goal_catalog.json. A row is listed only where the same record or the same concept is rendered in more than one place; conditional alternates (a panel that changes wording when a feature is off) are not listed.

Cross-links already in place, which the suggested homes build on: the dashboard header's "How the model works" link, the Tests tab's component links into the explainer's Architecture tab, and the explainer header's link to the dashboard's Now page.
