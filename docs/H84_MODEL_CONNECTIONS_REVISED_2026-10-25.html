The goal includes moving the whole body.

A ball can be too far from the hand at first. The useful ability is to move the body closer, reach, grasp, and keep hold. Learning must discover which movements work together.

The repair does not supply a list such as “crawl, reach, close fingers.” It supplies the missing way to compare possible movements using their predicted consequences. Practice must teach those consequences.

Why the old route falls short

The active body planner mainly compares the predicted body pose with a pose saved from a past observation. Its narrow check favors improvement after one short command.

That can reject a useful first movement if its benefit appears only after another movement.

What the repaired route must compare

Each possible sequence starts from the same observed body and surroundings. The prediction includes where the body moves, what it touches, and the effect on its condition.

A useful later result must be able to change which first command is chosen.

Physical movement and learning are separate questions. The simulator allows the body to move through joint forces and contact with the floor. Whether this particular body can perform a chosen movement, and whether training teaches it to choose that movement, both need physical evidence. A connected prediction loop provides a route to learning; it does not guarantee every attempted reach succeeds.

The proposed complete loop

A command contains requested positions, turns and strength for body parts. A sequence is several commands in order. A predicted state is the model's estimate of the body and senses after a command.

1. Start from observationsUse the current body pose, senses, condition and control settings. Make several possible command sequences.
2. Predict each sequencePredict the result of its first command. Start its second command from that predicted result. Continue through the sequence.
3. Compare later resultsCompare expected bodily condition and useful experience. Include benefits beyond the short prediction window using learned forecasts of later results.
4. Send the first commandExecute it through MIMo's actual controls. Observe the result before choosing again. Keep the unused part of the chosen sequence as one option.

Learning connects the end back to the start: pair the command that was sent with the result it caused. Use the prediction error to improve future forecasts. Keep the real experience separate from imagined possibilities.

Wellness means the model's measurements of how well the body is doing, such as comfort and ability to control movement. The repaired choice must value keeping a good condition even after that behavior is familiar. Learning progress is a separate reason to explore; it cannot be the only reason to continue a useful movement.

Why would the body approach an object?

An object becomes worth approaching when experience links interacting with it to comfort, bodily needs or learning a reliable effect of movement. The repaired chooser must carry that learned value into its predictions. Seeing an object alone does not provide that value.

For example, contact may teach that a movement can produce a repeatable, useful result. The repair must let that learned connection affect a later choice, even when contact takes several movements to reach.

Where FK and IK fit

FK: joints → body positions

Forward kinematics (FK) calculates where connected body parts end up from their joint bends. Changing the shoulder changes the elbow's position; changing the elbow then changes where the hand can be.

IK: requested positions → joint bends

Inverse kinematics (IK) searches for allowed joint bends that place body parts near requested positions. If no allowed bends reach the point, it must report the remaining gap.

Use these calculations to keep imagined body positions consistent with connected bones and joint limits. They do not predict whether muscle force overcomes gravity, a foot slips, or fingers hold an object. The forward model must learn those physical consequences from actual movement and contact.

What will count as completing the repair?

  1. A later result changes the first choice. Changing an early command must change later predicted states. A predicted later benefit must be able to select a first command that briefly worsens hand distance.
  2. Useful behavior survives familiarity. Keeping a beneficial condition must remain selectable when learning progress is zero. A useful goal must survive repeated planning until achieved, invalidated or replaced for a measured reason.
  3. The chosen command reaches physics. Saved records must identify whether the sequence chooser or exploration supplied it, and pair it with the correct observed result.
  4. Actual abilities improve. Compare from matched starting conditions, then check repeated attempts, retention after more learning, and changed starting positions. Use actual object contact and movement.
  5. Existing learning survives the repair. Save/resume must preserve the old learned state and the new continuation state. Review temporary files and update the existing ability summary when the result is recorded.

Adversarial review: gaps that changed the proposed solution
  • Recording only the requested eye direction was insufficient because controls can change it before physics.
  • Saving the new command beside the previous result would teach the wrong cause. The record must follow one completed movement interval.
  • Body-position carry alone leaves head, control and memory state incomplete.
  • Learning progress as a requirement for useful choice would discard familiar beneficial behavior.
  • A short sequence and a briefly retained pose do not supply value for delayed outcomes.
  • A command selector needs a real connection to physics and an exploration path that actually runs.
  • Joint geometry does not supply contact dynamics; a hand-following toy does not supply physical grasp evidence.
  • A new body predictor starting from zero would bypass useful learned movement knowledge. The revised design reuses the existing prediction and learns a correction.

Research basis for value beyond a short prediction

Learning an estimate of later outcomes alongside a world model is an established approach to long-horizon behavior. The Dreamer paper combines imagined trajectories with learned value estimates. That supports this design direction; it does not establish that the proposed H84 implementation works. H84 will use its own bodily measurements and preserved experience, with no special ball-distance score.
