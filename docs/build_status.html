Reading the build's records…

The VS Code extension's agent count leaves out agents that run inside a workflow, so this page reads the workflows' own records: Source/Python/mimo_bridge/tools/build_status.py --watch writes Saved/mimo_bridge/build_status.json every 15 seconds and this page re-reads it every 10 seconds. "Last active" is when the agent last added anything to its transcript (the file the builder keeps of its work); a running agent with nothing new for more than 10 minutes is marked. Each agent's own log is a file in docs/gain_of_function_v3/agents/; select an agent's name to open it. The plan is DESIGN.md and the step-by-step record WORKLOG.md; all master files: index.
