1 • The setting

What the system is, what this plan builds, and which parts are involved

MIMo is a simulated infant body: a MuJoCo model file with 75 geom tags, every one a primitive shape (sphere, capsule, cylinder or box) and 0 mesh files, 97 joints and 92 motors (inventory2 mimo-body). MuJoCo is the physics program, written in C, that moves the body when the motors push. UEMA is the learning program that controls MIMo. Every model step (one 50 ms model update) it reads six senses (vision, tactile, audio, proprioception, motor, vestibular; intermind is inactive in the released run: trainer.log, inventory1), turns each sense into one token (192 numbers; encoder_registry.py:33), predicts the next tokens, and keeps the motors supplied with a command (26 body handles × 9 numbers: target position in cm, orientation as a quaternion, radius, strength 0 to 1; README.md:19).

The released model has 18,131,745 parameters (README.md:27; 0 is no model, 271M is the UEMA specification's full configuration), d_model 192, 4 transformer blocks, context 128 model steps (args.json:142), saved at model step 494,025 as a checkpoint whose weights file is 73,119,988 bytes (MANIFEST.json:120). Its scene is "crib" (mobile, critters, a responsive caregiver), body age fixed at 24 months, body layout trunk_v1 (args.json; inventory2 mimo-body).

This plan builds three things on one Git branch. Target A: the same Python trainer runs on an Apple-silicon Mac, on the Apple GPU through torch's "mps" device or on the CPU. Target B: a Swift package (UEMAKit) and a SwiftUI app (UEMAMind) run one body with the released weights on macOS and iOS without Python. Target D: the documents and build files that go with A and B.

Terms used from here on. Wellness is the model's own score of a model step (a sum of wellness channels; 295,914 parameters in the receipt); the goal ring ranks its 200 entries by it. CUDA is NVIDIA's GPU interface; MPS is torch's Apple-GPU device, built on Metal, Apple's graphics and compute interface. autocast runs chosen operations in a shorter number format (bf16, 16 bits); float32 and float64 are 32-bit and 64-bit numbers. MLX Swift is Apple's array and neural-network library for Swift, with gradients and Adam (research1 torch-apple). A Swift package is a folder with a Package.swift manifest; an XCFramework bundles one compiled library per Apple platform; XcodeGen writes an Xcode project from a project.yml file; SwiftUI is Apple's declarative user-interface framework; SceneKit is Apple's 3D scene framework, rendering through Metal. A Swift protocol is a named list of functions a type promises to provide. qpos and qvel are MuJoCo's arrays of joint positions (146 numbers for this body) and joint velocities; ctrl is its array of the 92 motor controls; mocap bodies are bodies whose pose code sets directly each model step. Goertzel is a computation of one frequency band's power from a short history of samples (here, contact force per skin patch). A fixture is a file exported here from the released weights that a Swift test compares its own numbers with.
