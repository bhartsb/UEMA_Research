What the recovery rehearsal exposed

A copied body experienced contact with a visible physical sphere. Each candidate movement started from the same saved physical state. Repeating a command reproduced the measured body and function trajectory exactly.

The rehearsal did not establish a reason to move. Removing the source could leave the same recovery trajectory as holding still: the effect of earlier pressure takes time to fade. Changes in muscle effort could also dominate a combined measure when sensing was still functioning.

The experiment now requires an ongoing effect of the source and improvement over holding before it can claim a recovery opportunity. It records skin and motor functioning separately. A wider pressure-position sweep is retained as a negative setup result, not treated as failed learning.

The next copied-model comparison

The immediate comparison asks whether the existing self network can learn the local consequences of movements. It uses actual pressure-related sensing changes and actual muscle capacity. Object coordinates and desired movements are not supplied as answers to the network.

Training arrangements and unfamiliar test arrangements are separate. The learned forecasts must beat both ignoring the action and the same network before the copied practice. Predicting the average body state correctly earns no action-prediction credit. Every test world reloads its checkpoint; runtime adaptation cannot carry between worlds.

This narrower prediction comparison can run even when the pressure setup cannot establish purposeful recovery. Its result cannot authorize the new chooser. A positive recovery test still needs a reachable movement-dependent outcome, followed by correction, completion and retention tests.
