How to read this. Each box is one training run. The chip strip at the top of a box holds the numbers that decide anything: whether the running code matches the current source, whether the executed action reached the model, which way causal prediction error moved over report windows, whether the body follows commands, and the five-control causal test. Every value on this page is computed by the dashboard script from the run's own files at render time; free text typed by an operator is labelled as such. Scientific status. Contacts, rotation angles, body-discrimination ratios, and gaze heuristics are observational proxies. They do not by themselves establish purposeful behaviour, situational awareness, a learned self-model, or valid imagined rollouts; consult the causal-control and mechanical-milestone results. "Guessing the next instant" = prediction error of the next observation given the state and the executed action; lower is better, and comparisons use first-window vs last-window means, never single records. "Simulator physics frames per second" = 10 ms physics frames. The model observes and learns only once per action-repeat interval (normally every 5 physics frames = 50 ms), so physics FPS is not model-update FPS. "Curiosity drive" = a deterministic function of recent prediction error, nonzero only inside the run's configured band. "Snapshot" = all model weights saved to disk. Sense names are the model's own: vision is what the two eyes see: a wide view and a sharp centre for each eye, as pixels; tactile is the skin's sense of touch: up to 32 skin parts at once, each with its pressure, rub, slip, contact area, vibration and push; audio is what the two ears hear: how loud each of 256 pitch bands is at each ear, plus two numbers for the sound's direction; proprioception is where each tracked body part is, how it is turned and how fast it moves; motor is the command the body was last given, beside the pose each part reached, read back as an input; vestibular is the body's load and balance in 29 numbers: which way gravity pulls on the head and how the head turns, the neck, which way is up for the trunk, what carries the weight, effort, joints at their limits and fatigue; intermind is a reserved input for other minds' summaries, placeholder noise for now.
