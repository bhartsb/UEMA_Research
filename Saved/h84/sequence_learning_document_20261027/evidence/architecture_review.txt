RECOMMENDATION

Use UEMA's existing temporal Transformer state, motor policy, forward prediction, wellness evaluator and intention mechanism as one learned feedback system. At each qualified 50 ms decision interval, propose a coordinated body/eye/finger command from the current temporal state and retained intention. Predict its consequence, advance the predicted temporal state, and call the same policy again. Continue for 60 transitions, representing three seconds. Compare a small set of such trajectories with the previous trajectory and controller proposal. Execute only the first command, then rebuild the decision state from actual sensations. The next prediction begins with the measured consequence, not the old imagined consequence.

This is the best justified starting approach for this repository, not an experimentally established winner. It avoids replacing the retained controller and forward model unnecessarily. It allows learned immediate correction without making a weight update a prerequisite for each correction. Multiple neural heads are acceptable; independent, inconsistent clocks/state histories/targets are not.

The six 500 ms pictures are an explanation convention. They must not become six compulsory command latches. Contact, gaze and a single finger can change between them. Fifty milliseconds is a proposed model decision clock supported by existing conventions; wall-clock throughput, short-duration prediction calibration and execution semantics still require qualification. Physics safety/contact enforcement can run at the simulator's smaller step. A larger contact-control delay cannot be solved by renaming a 500 ms phase.

SOURCE FINDINGS THAT CHANGE THE DESIGN

1. D:/UEMA_wt/causal_loop_20261025/Source/Python/lem/model/motor_controller.py describes an existing policy MLP: newest Transformer token per sense, handle state and wellness gradient enter; one coordinated handle command leaves. Calling for 'a policy instead of MLPs' is a false architectural contrast. The useful question is its temporal input, output ownership and training objective.
2. lem/model/forward_model.py implements cross-modal, causal-temporal and full cross-modal bridge attention. It can carry a past sensory sequence. The bridge is not causally masked across time. Supplying future observations in a new parallel sequence-training input would leak the answers unless every cross-time path is masked. Existing past-only prefix use does not by itself show leakage.
3. mimo_bridge/lem_model.py around8004 forces max_steps=1 on the physical-goals memory route because later sensory depths do not advance physical pose. A separate non-world hand-target branch also forces max_steps=1. This is a real route restriction. More training does not remove it. Removing the restriction alone does not provide correct later-state prediction.
4. mimo_bridge/native_contract.py has a useful requested/sent command contract, gaze, finger joint goals, duration and advancing context. Its rollout documentation also labels held/frozen parts of future memory/state. Every quantity consumed by the next policy or wellness call must either advance or be explicitly invariant. A prediction of body positions beside unchanged contact or object state is not a full motion forecast.
5. lem/model/intention_generator.py already distinguishes the useful consequence-mediated wellness path from an action shortcut: the motor token is detached for prospective scoring. Preserve that protection. Do not let predicted wellness improve simply because the proposed command numbers changed.

CONCRETE LEARNING CONTRACT REQUIRED IN THE REPORT

A. Every real transition contains timestamped starting sensory history, intention, requested command, actual filtered/sent command, actual duration, next sensations, observed wellness components, termination/reset flags, and model/schema versions. Keep raw observations where available. Action-conditioned prediction learns from what was actually sent. Future motor ledgers and hidden simulator object identities are not pre-action inputs.

B. Sample contiguous experience windows. Use a real past prefix to reconstruct temporal state. Train one-step predictions and autonomous multi-step predictions against the corresponding later observations. In autonomous rollout, feed predicted state into the next transition; do not refresh it with the correct future observation and call that open-loop prediction. Begin training at shorter durations while retaining a curriculum to the complete three seconds. A three-second planner can be specified before qualification, but cannot be called dependable on the basis of one-step accuracy.

C. Predict signals that can change the next command: body/root motion, relevant visual or object representation, individual joint state, contact onset/release, pressure/slip and estimator uncertainty. Preserve true contact discontinuities; continuous motion does not mean constant velocity, smooth contact force, or zero prediction error. Classify contact and model conditional distributions where a single squared-error average would invent physically implausible contact.

D. The policy needs an explicit delayed-credit objective. Copying every past command is insufficient. A coherent actor–critic route is: a critic learns discounted future UEMA wellness from observed transitions and/or bounded, qualified imagined trajectories; the policy increases the probability of commands whose predicted return exceeds the critic's baseline. In a score-function implementation, loss is minus log probability of the sampled coordinated command multiplied by a detached return advantage, with controlled exploration entropy. In a differentiable implementation, freeze world-model and wellness parameters while allowing derivative flow through their consequences to policy parameters. Choose one route in the report, do not leave 'train the policy' unexplained. Non-differentiable filters must be included in the action contract; an imagined gradient through a nonexistent physical path is invalid. Old-controller distillation is useful initialization/preservation, not the final ability-learning signal.

E. A three-second explicit rollout is not a declaration that all value ends at three seconds. State whether terminal value represents continuation under the same policy and goal-update rule, and train that value using actual durations and terminations. Avoid counting predicted first-three-second utility twice. For a goal-conditioned critic, every real transition includes both current and next intention, so a goal switch has a declared target: bootstrap the successor's value under the actual higher-level selection policy, or terminate a clearly defined goal episode with its measured outcome. Never invent an unobserved continuation or erase failure costs when a goal changes.

F. Retained intention is useful when it conditions coordinated movement; a compulsory six-second lease is unsupported. Compare continuation and replacement through the same generic wellness/continuation criterion. Preserve history and the previous intention in the state so learned switching behavior can depend on interrupted effort and observed consequences. A learned termination/selection mechanism is an architectural option, not a named grasp-phase script. If switching cost is used, it must correspond to actual cost or be identified as an engineering regularizer, not fabricated human timing.

G. Preserve the meaning of existing wellness channels initially. Do not silently replace them with object-grasp distance or a newly invented capacity equation to force the desired demonstration. Test whether their measured values distinguish useful controlled contact from uncontrolled collision and from comfortable inaction. If the objective gives no benefit to useful interaction, changing the policy architecture alone cannot make it prefer grasping. That would require an explicit, justified objective decision, not an alleged training fix.

H. Prevent model exploitation: qualify multi-step predictions on held-out actual episodes, including the highest-scoring selected candidates; compare predicted advantage with actual matched outcomes; use uncertainty-aware ranking or conservative value estimates. A predicted reward optimum can be a prediction defect. Imagination teaches candidate behavior; real interaction supplies the evidence that the candidate really works. Do not allow the planner/policy to update the wellness teacher to flatter its own actions.

I. Transients need two responses. A surprising but physically healthy observation updates temporal belief and the next command immediately, and becomes a learning example. Actual harm/invalid control triggers the existing physical guard. Do not freeze or abort every novel low-confidence movement: that prevents learning. Use the established bounded physical exploration envelope where prediction is unqualified, retaining unsuccessful transitions and failures. Do not average all disturbance samples away or train a universal hand-coded reflex for this example.

J. Preserve checkpoints, optimizer state, replay, all worlds, pending lessons and random state. Add losses/heads with versioned targets and matched preserved-state comparisons. A new head with preserved old weights is not evidence that old behavior is preserved. Readouts that change coordinates need re-encoding or schema-separated replay. Do not overwrite old physical evidence or reset the body to make recovery easier.

WHY NOT THE ALTERNATIVES FIRST?

Blind action chunks: capture coordination but can miss unexpected first contact while the chunk executes. They remain compatible if a short prefix is executed and a feedback controller can revise the rest. An unconstrained six-command list cannot demonstrate continuous correction.
Diffusion/action-sequence Transformer: a serious candidate if simple proposals cannot represent multiple coordinated movement choices. Diffusion Policy demonstrates sequence generation and receding-horizon manipulation, but its imitation setting and inference workload do not establish the best autonomous UEMA learner. It is not necessary to replace a functioning temporal core merely because the illustration contains six phases.
Independent MLP repairs: output heads are ordinary and useful. Trouble comes when each head has different hidden state, duration, target semantics or execution path. The new report should define one state/command/outcome contract and trace every output into the next transition or score.
Pure open-loop optimizer: can overfit prediction errors and relearn a trajectory on every decision. A learned policy provides experience-based coordinated proposals and fast feedback; imagination improves its decisions and training. Keep enough alternative trajectories to discover a better approach, but do not disguise thousands of arbitrary command samples as learned coordination.

ADVERSARIAL FAILURE CASES / REQUIRED DECISIONS

1. Actor produces a three-second table but ignores new contact for500 ms: fails correction requirement.
2. Early trunk movement worsens immediate hand distance but enables later reach: must improve return through delayed credit, not be discarded at first local decline.
3. Index touches earlier than predicted: next sensed state must permit reducing its closure while changing thumb/other digits, without a special 'index-first' script.
4. Gaze turns and object disappears briefly: temporal belief tracks uncertainty; predicted hidden object state must not be promoted to an observation or a new object's identity.
5. Comfortable inactive body has highest generic wellness: learning may correctly learn inactivity. Identify objective mismatch rather than pretend more sequence training guarantees grasping.
6. A successful illustration is copied by an IK pose script: useful geometry explanation, invalid learned-ability evidence.
7. Moving object is attached to hand by environment code: invalid free-object grasp/lift result.
8. Planner predicts pressure using old unchanged skin state: false robustness. Contact history needs to advance in every imagined row.
9. Policy learns only the current planner's flawed actions: no independent delayed-credit improvement. Show the actual policy learning signal.
10. Multi-step training uses future observation tokens through the unmasked bridge: invalid sequence prediction. Mask or use past prefixes and independently verify no future dependence.
11. Learned fallback corrects every model error while actor never improves: report intervention rate and native policy recovery separately; physical guards should not secretly supply a task sequence.
12. Zero error demanded at every50 ms row: impossible/nondeterministic contacts become blockage. Evaluate calibrated prediction and resulting correction, not omniscience.
13. Three-second horizon chosen as universal duration: wrong. It is the full-motion target for this example; longer tasks need continuation value or a longer/hierarchical horizon, without six fixed phases.

DECISIVE, AUTHORIZED-LATER COMPARISON

After source closure and separate runtime authorization, use protected starting states and a free object beyond arm-only reach. Compare preserved baseline against the learned temporal policy using the same sensory/control path. Include undisturbed episodes and randomized small disturbances at different times. Measure complete reach/grasp/lift/hold success, correction latency, object retention, contact penetration and force, physical harm/support, prediction calibration by horizon, and guard intervention. Evaluate with learning off after training and after checkpoint reload; vary starting position/object size. Show how these measures change with real training, not just aggregate prediction loss. A paired/no-history or short-horizon ablation can establish whether sequence memory and delayed credit actually matter, but keep it within the named question's runtime budget. PRIMARY RESEARCH CONSULTED

DreamerV3 — Hafner et al., Nature2025, https://www.nature.com/articles/s41586-025-08744-2 . Supports a learned world model with actor and critic learning from imagined temporal trajectories. Does not establish UEMA contact accuracy or current rollout suitability.
TD-MPC2 — Hansen et al., ICLR2024, https://www.tdmpc2.com/ and https://arxiv.org/abs/2310.16828 . Supports learned latent planning with policy/value structure across continuous-control tasks. Does not establish that its hyperparameters or reward definitions suit UEMA.
Diffusion Policy — Chi et al., RSS2023/IJRR2024, https://diffusion-policy.cs.columbia.edu/ . Supports multimodal action sequences and receding-horizon manipulation. Not evidence that imitation alone creates an autonomous useful-goal objective.

Overall review disposition: coherent architecture direction endorsed with the concrete learning, objective, timing, uncertainty and preservation conditions above. Do not call it a proven best solution before the physical comparisons. The biggest current design risk is attributing absent task usefulness or absent action-conditioned state evolution to a mere shortage of training.

CONCRETE ALGORITHM DELTA REVIEW

Parent proposal reviewed: retain temporal core and existing motor mean; stochastic finite goal selector chooses previous intention or a memory candidate; motor distribution produces coordinated commands; Q(s,g,a) learns one-step off-policy TD from real transitions, r + gamma times target continuation under the current goal/motor policies; actor maximizes Q using reparameterized motor samples and an exact finite sum over goal choices. A learned forward model supplies three-second rollouts of the same policies for planning. No goal-distance reward or fixed intention lease.

Disposition: coherent choice. A real-transition one-step TD critic avoids falsely assigning an entire off-policy three-second return to the current policy. It connects later wellness to early actions by repeated bootstrapping. Policy optimization through the learned Q also avoids requiring derivatives through every physical contact or through sixty imagined transitions. This does not by itself solve critic extrapolation or establish eventual success.

Required precision:
1. Define s as temporal belief, previous intention, estimator/filter state and wellness history. The newly selected g is a separate input to Q. Successor s' contains the actual selected g as its previous intention. Store both old and selected goals, actual next state, command and duration. Goals may change without pretending the world terminated.
2. Declare whether Q's action is requested or effective sent control. Prefer the effective filtered command that actually produces the transition. If actor output is a request, derive that effective command through the same production decoder/filter; preserve necessary state. A blocked or zero-gradient decoder requires an explicit optimization choice, not silently assuming its derivative is identity.
3. Exact expectation applies to the finite goal shortlist, not to continuous motor commands; approximate the latter with sampled commands. Recompute a comparable shortlist from successor state and versioned memory during target construction. Never label a never-pursued memory endpoint as an actually pursued goal.
4. Two target critics with a clipped lower target reduce optimistic bootstrapping. They are not certified error bounds. Check support and actual predicted-versus-real return, especially for action/goal combinations favored by the optimizer. Bounded real exploration must remain available when model/Q estimates are not qualified.
5. Target networks and the acting policy need a specified update schedule; old replay must be re-encoded with causal burn-in if encoder coordinates change. Normalization/producer versions belong in targets. Generic wellness changing during a window is a nonstationary target problem, not harmless implementation detail.
6. Terminal value in the three-second planner is continuation under the base learned policy, not automatically under the planner. This is a legitimate declared approximation. Do not claim that it predicts the exact planner-continued return. Compute it as the same goal-policy expectation and motor-policy sample expectation used by the critic.
7. Future sensory, contact, memory and wellness-producer histories must advance before the next policy call. Real execution always replaces imagined state with newly estimated actual state. The closed feedback loop requires both properties.
8. Sixty predicted transitions times K candidates does not establish50 ms wall-clock latency. The initial simulation can wait for a decision, giving a50 ms simulated-time correction interval. If a fast actor runs between slower replans later, the asynchronous version/age/stale-plan contract is a separate declared design; do not imply it is already handled.
9. Entropy regularization is an engineering aid to exploration, not observed wellness. Declare its coefficient and decay/calibration objective. Do not change score semantics invisibly to make a movement look worthwhile.

No conceptual contradiction found in this actor–critic plus policy-rollout planner choice subject to these conditions. Its key empirical comparison remains actual learned sequence completion and disturbance recovery with the same unmodified generic wellness objective.
