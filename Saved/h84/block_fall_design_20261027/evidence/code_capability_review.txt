3. CROSS-MODAL ATTENTION: CORRECTION TO AN OVERBROAD LEAK CLAIM
Read forward_model.py in full, including action-conditioned prediction and imagination methods.
- Stage1 (lines123–137) reshapes to [batch*time, modality, width]. Modalities at ONE timestamp can attend each other. No cross-time leakage is introduced by this stage itself.
- Stage2 (lines140–157) reshapes to [batch*modality,time,width] and passes attn_mask=self.causal_mask. Mask construction at64–67 excludes later time positions.
- Stage3 bridge (lines160–173) attends across the full flattened time×modality sequence with NO mask: calls at166 and169 have no attn_mask. Therefore an output labelled as an EARLIER supplied time can depend on a later supplied time. Later blocks do not restore per-token causality.
- forward() lines370–374 concatenates historical context with the current frame. Lines420–424 return newest last_step separately, plus current_flat captured BEFORE the attention blocks as the context update. It does not store rewritten earlier block outputs as the new historical frame.

This source is NOT a fully causal all-timestamp Transformer. However, unmasked bridge attention over an already-observed prefix is not automatically future leakage at the CURRENT decision time. Relevant actual consumers:
- lem/training_step.py:860–882 calls forward_model, then prediction_heads(last_step); target gathering follows at895 onward.
- mimo_bridge/lem_model.py:3437 and3461–3464 heads consume last_step on live current-prefix inputs. Its current-frame reconstruction/error path must not be relabelled as an unseen-future forecast, independently of attention.
- replay_update: lines5466 onward explicitly split context first ctx-1 moments, current moment ctx-1, target moment ctx. ctx at5481 contains the earlier prefix; forward_model(cur,ctx) at5585 and heads(last_step) at5587 do not insert the target frame into the input. Target error is computed at5607 against nxt. Saved memory/self state must belong to that sampled decision (checks at5574–5583).
- motor_controller.py:140 onward takes the newest n_active slots, despite receiving the full latents array.
- imagine_step forward_model.py:564–575 supplies predicted continuation tokens, advances pre-block context, and decodes last_step. Predicted futures are allowed imagination inputs; measured future observations are not.

Conclusion: the inspected principal live/replay routes do not show the asserted 'existing earlier forecast saw its actual future' defect solely because the bridge lacks a mask. They recompute a newest decision from its observed prefix. The clear hazard is scoring many earlier timestamps in one concatenated future-containing training window as if each was a forecast made then. Doing that without a cross-time bridge mask would leak labels. Same-time cross-modal exchange should be preserved.

4. BEST INFERENCE / RETROSPECTIVE LEARNING SPLIT
For current checkpoints, preserve prefix-only newest-output inference until an explicit migration comparison. This is a coherent causal decision procedure even when internal representations of the observed past are retrospectively updated.
For efficient parallel multi-timestamp sequence prediction, every cross-time attention path must mask keys whose timestamp exceeds the query's information cutoff. The bridge mask should be time-block based: allow all modalities at the same timestamp, all valid past timestamps, and no later measured timestamp. A simple token-level lower triangle would arbitrarily block same-time modalities according to serialization order. Physical sensor arrival times and outgoing-action timing also need declared ordering.
Retrospective learning may see later outcomes as TARGETS and can use a separate bidirectional teacher to reconstruct a completed episode. Such teacher states are hindsight representations, not available acting observations. Do not feed them into actor/critic inputs at an earlier decision or record their teacher-forced accuracy as autonomous future prediction. The policy/student still receives its causal prefix; any teacher-distillation target must be labelled accordingly and qualified on prefix-only rollout.

A future authorized qualification should mutate later measured observations while preserving the prefix and require unchanged earlier forecast outputs in parallel-causal mode; compare latest prefix outputs against the established single-prefix path, and test shuffled/time-shifted action controls plus free multistep prediction. Same-time sensor perturbations SHOULD be allowed to change same-time state estimates. These are concrete discriminating checks, not executed in this stopped design-review task. Preserve weights, optimizer, world and memory state; a new mask is a semantic model change to compare, not a harmless blanket bug fix.

Document wording recommendation: 'The model already combines senses at each moment and remembers a past window. Its current prediction uses the newest moment. To teach many moments together without accidentally showing an earlier prediction a later answer, we must also block later timestamps in the bridge between senses. Looking back over an episode is useful for learning; acting must use only information already received.'
