RECOMMENDATION
Extend the existing sequence-learning and memory paths. Do not add a separate action/wellness attention network merely because the goal ring stores individual moments. The code already has recurrent memory, attention, executed-action sequence forecasts, and retained sequence lessons. The missing contract is coherent coverage: preserve the relevant chronology, predict its actual bodily consequences at several future times, and connect those forecasts to the existing intention comparison. Attention alone supplies neither causal credit nor a reason to choose an outcome.

The useful unit is a CONTEXTUAL TRANSITION SEQUENCE, not an isolated command or a wellness derivative. It contains the starting bodily/world state, actual overlapping commands with their durations, observed intermediate transitions, absolute bodily-condition components, and observation reliability. Goals describe what was sought; prediction error describes what the model did not understand. Neither replaces the physical outcome.

WHAT TO CONNECT, AND WHY
Commands plus wellness: tells which order preceded a bodily change, but cannot separate a command from the state that caused both the command and the harm. Use as conditioning, not causal credit by itself.
State transitions plus wellness: preserves actual loss or improvement and distinguishes stable health from stable injury. Necessary target, but omitting commands cannot answer what another movement would do.
Goals plus outcomes: tells whether the same physical change helped a continuing intention. Store goal identity, timing, and progress, but an intended goal is not evidence it was achieved and must not silently become a task reward.
Prediction error plus transitions: identifies surprising consequences and where additional learning is useful. Keep model error distinct from pain. Expected injury still hurts; harmless novelty can be surprising. A noise source should not look like an inexhaustible learning opportunity.
Entity/context plus all of the above: distinguishes catching a supported light object from catching a heavy falling object, and the same command in a rested or fatigued body. Names can aid retrieval but must not substitute for sensed conditions or establish causality.
Several time spans: preserve rapid contact events, seconds of coordinated movement, and slower changes in bodily function. Existing entity-self correlations operate at different, much longer windows (mimo_bridge/entity_self.py:79-107). They cannot substitute for precise within-movement timing.

SMALLEST COHERENT CHANGE
A. Reuse the executed-command ledger and existing SelfHistory/SelfRehearsal windows. Define one versioned sequence record with body/episode identity, physical interval start/end, pre-action observation and validity, commands actually applied, intermediate outcomes, body-function regime, and selected intention. Preserve full command vectors, including simultaneous eyes/body/fingers and their separate timing. Do not infer execution from a proposal.
B. Keep a dense recent causal buffer at the available model-step cadence, with interval summaries from the physical producer where needed. A peak or impulse occurring between model samples requires a producer-side measurement; attention cannot recover an event never recorded. Longer memory can compress older history. Keep the existing uniform rehearsal half, and make the changed half inspect the WHOLE trajectory rather than endpoint difference alone. Preserve the complete local window around a selected event, including its lead-in and recovery, instead of retaining only its peak. Priority affects study opportunities, not the body's motivational objective.
C. Reuse the existing self forecast and predictive transition with action/duration conditioning. Predict component trajectories and validity, using actual outcomes as targets. Start with measured horizons already supported; add a whole-motion horizon and longer condition forecasts only where the relevant targets and timestamps exist. A3s comparison needs the whole3s consequence, not six independent500ms endpoint scores. Coarser long-range summaries must retain duration and sharp-event information; averaging alone can erase a damaging impulse.
D. Train prediction, not a new observation-to-command reward policy. The sequence loss compares predicted observations/function with later actual observations/function. Hold model parameters fixed while the planner compares candidate commands. Optimizing candidate commands through a frozen model is different from teaching an actor's weights to maximize a return. Existing learned motor networks are part of UEMA; the presence of an MLP alone does not make a prohibited policy.
E. At each real feedback point, update the present belief and compare feasible CONTINUATIONS from that same state, including useful stillness. Score predicted absolute condition over the whole physical interval with UEMA's declared intrinsic wellness contract, alongside the ongoing intention. Do not substitute normalized goal-ring deviations, positive derivatives, prediction surprise, or contact pressure for that contract. Choose a short executable part, then observe and replan. Permit temporary worsening of immediate goal distance when later predicted outcome justifies it. The predictor needs future physical pose and evolving bodily state to compare such continuations, not a held initial pose labeled as future motion.
F. Two explicit decisions remain necessary in a complete implementation proposal: which raw component producers and forecasts represent intrinsic wellness over time, and how their severity/duration combine in the planner. Reuse the current semantics where defensible; do not invent hidden weights, emergency thresholds, or a scalar reward-trained actor. A large brief pain signal must retain its calibrated meaning rather than disappear in a long average. This is a specification of the body's intrinsic consequences, not something attention can decide from unlabelled correlations alone. The next design record must show its numerical behavior on the counterexamples below before implementation.
G. Retain body/function/model-coordinate provenance. Store raw or stable observations sufficient to re-encode with current weights, or explicitly migrate old latent coordinates. Old events remain evidence, but a stronger or injured body may need different actions. Distinguish invalid/missing sensing from a healthy low reading. Do not supply hidden clean simulator state to the actor merely to make forecasts succeed.

COUNTEREXAMPLES THE DESIGN MUST PASS
Catch blamed for a fall: from the same already-falling state, catch causes some pain but prevents greater impact; from an earlier stable state, staying balanced beats deliberately falling and catching. Compare alternatives at EACH decision time. Low post-catch wellness does not establish that catching caused the original fall.
Relief exploitation: a hurt-then-recover sequence has a large positive rise; an uninterrupted healthy sequence has none. Summing positive changes rewards the first. Absolute trajectories retain the preceding harm and favor remaining healthy when other outcomes are equal.
Stable wellness: holding an object securely may require continuous force with no wellness change. A derivative-only rule mistakes successful maintenance for useless action. Predict what happens under maintained force versus release from the same state.
Delayed benefit: a support shift can briefly cost effort or increase distance from the ball, then enable a secure reach. The full trajectory and ending condition must distinguish it from stopping early. Do not prune it merely for a worse intermediate distance.
Noisy derivatives: small alternating reading errors create large accumulated positive changes. Use observed component trajectories with validity/uncertainty; a diagnostic trend estimate is not a reward. Check fixed physical conditions with varied measurement noise.
No-op: rest may be the correct response under fatigue, while silence/no movement cannot be accepted as evidence of newly acquired control. Compare actual capability/goal outcomes rather than add an arbitrary activity bonus to prevent stillness.
Lost sensing: a numb or disconnected contact sensor may report less pressure and prediction error. Lower signal must not be mistaken for relief or improved bodily function. Function/validity changes and later task-relevant consequences belong in the forecast.
Changing body: a command that safely caught an object before fatigue or growth can fail now. Retrieve on current capacity and context, forecast again, and check mismatch rather than replay the old command as a fixed skill.
Transient recovery with identical endpoints: a brief damaging contact followed by recovery can leave endpoint function unchanged. Require accurate intermediate pain/function trajectory and retention of that event window.
Entity confounding: support furniture or another actor may be present during both difficult tasks and low wellness. Presence correlation does not say removing that support improves wellbeing. Keep context and action-conditioned alternatives; use controlled physical comparisons before causal claims.

DISCRIMINATING TESTS FOR LATER AUTHORIZED WORK
1. Temporal information test: at a decision cutoff, change every later observation while keeping the available prefix fixed. Earlier predictions and choice must be unchanged. Also change a later action and confirm it cannot alter an earlier predicted outcome. A fully completed OLD episode may be retrieved today; the later outcome of the decision currently being replayed must not leak into that decision's memory.
2. Retention fixture: use a timestamped stable trace and a trace with a brief middle function/pain event, equal endpoints, and high-amplitude irrelevant sensory changes. Check whether the complete event chronology survives retention, alongside uniform stable experience. Compare current endpoint priority with whole-window retention. This isolates storage from any learned forecast claim.
3. Catch comparison: from preserved identical physical states compare catching and not catching after loss of balance; separately compare balanced continuation and initiating the fall from an earlier state. Measure time-resolved contact, function, pain, actual outcomes, forecasts, and selected continuation. Goal: avoid the initial bad transition while retaining the helpful recovery, not simply label all movement near pain as bad.
4. Whole-motion comparison: same initial state, a direct reach, a supportive shift followed by reach, and a hold alternative. Ask whether a forecast over the full motion predicts the advantage that a single endpoint/short horizon misses. Inspect temporary distance increases and the exact executed eye/body/finger timeline.
5. Transfer and attribution controls: changed capacity/context, shuffled command identities, reordered command sequences with the same set of commands, and equal-duration prefixes. A forecast that ignores order or executed commands must lose the appropriate prediction advantage. Evaluate stable-condition accuracy and transient detection separately so common healthy samples cannot conceal missed rare harm.
6. Sensing/noise comparison: retain physical state while changing measurement noise or validity, and contrast a real recovery with a disappearing signal. Confirm no improvement is credited to sensor loss, and a predictable harmful event still carries harm.
These are proposed decision-changing comparisons, not launched jobs. Reuse existing preserved state and runner. Any diagnostic package must declare its question, remaining cumulative900s budget, exact command, output ownership, and completion receipt before authorized execution. No broader test framework is needed to answer the initial storage/causality questions.

REVIEW CONCLUSION
The earlier suggestion was directionally right about context, timing and delayed consequences, but overstated the missing architecture by omitting substantial existing sequence mechanisms. The strongest design is to repair and connect those mechanisms, not stack another generic memory/attention component on top. First settle event preservation, full component forecasts, and the continuation reader together. Treat source-written isolated extensions separately from saved-run settings and actual ability evidence.
