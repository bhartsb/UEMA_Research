REMAINING MATERIAL FINDINGS

R2-01 — A goal-conditioned target needs an actual goal-conditioned behavior.
Section F gives V(S,g) and a G target for 'each real window', but B/G use exploratory windows that were not executed under g. A future endpoint retrieved as a possible goal is not evidence of the return of pursuing that goal. Merely saving behavior-policy versions does not correct this mismatch. Needed: define the actual policy whose value V predicts; train goal-conditioned targets only from windows executed with that retained goal and policy, including failures, or choose and specify a valid off-policy learning method. Exploratory windows can still train forward predictions and supply retrieval seeds. Parent agreed to the first route; the pinned revision does not yet say it.

R2-02 — No qualified tail leaves the prefix score independent of the retained goal.
In the pinned score the only occurrence of g is V(S[60],g). With the tail unavailable during warm-up, the utility of a given action table is identical for every goal. B also selects goals through an unqualified later-value head, so its cold start is undefined. Required: say how an initial actual goal is chosen and how it affects finite-horizon action selection before value qualification. Goal-conditioned retrieval alone must not be described as a distance/achievement objective if the score has no such term.
Parent proposed explicit potential shaping. This is a workable fixed-goal search heuristic with important qualifications: use distance to the desired feature intervals (zero inside), fixed units/tolerances and mandatory validity. Keep the same g over each target window. Choose or replace goals using unshaped predicted bodily/control utility; the shaping offset -phi(S0,g) differs across goals and must not let farther initial distance manufacture value. Consistent discounted shaping telescopes: with an exact full continuation it changes Q only by a state/goal constant. With the tail absent it is an explicit finite-horizon heuristic, not an observed bodily benefit. Alpha=1 is a new declared design setting. Do not claim that shaping creates durable utility for an otherwise worthless grasp.

R2-03 — The full set x[k,c] still lacks defined forecast producers.
E's joint, object and skin heads cannot by themselves calculate every channel listed in F. Source _wellness_channel_vector (lem_model.py:10085) includes history- and learning-dependent controllability, learning progress, agency, consequence and other channels. Existing approximate wellness sees only part of this set. Required: identify the existing/new raw-channel readout, its actual pre-detrend targets, and every branch-local history used for derived terms. Missing channels must not be called complete merely because a vector has a slot for them.
Learning progress is a special case: a fixed-parameter imagined rollout has no real optimizer updates to measure. Predicting it requires a separate update-effect model with learner-state inputs and actual before/after held-out error targets. Otherwise choose an explicit exploitation contract with its learning-progress planning weight zero, and use actual measured progress to allocate bounded acquisition. This is a declared departure from the production weights, not silent omission. Parent selected this direction. Marking LP both mandatory and unavailable would reject every useful forecast forever.

R2-04 — Frozen per-comparison normalization does not freeze value target meaning.
F freezes N_c for each candidate comparison, but a value model trained across many windows can see different normalization snapshots. V(S,g) contains no normalization identifier/input, while G contains N_c(actual_channel). The same raw consequence then has different target units. Required: pin a policy/representation/normalization epoch for both value data and model, or predict raw channel integrals and transform them consistently (including the discounted time integral for the centering offset). Re-encoding old images alone cannot fix changed reward units. Parent agreed to epoch pinning; final wording needs to name all three contracts and pending-window behavior.

R2-05 — 'Complete observed returns' needs a finite horizon or a real termination.
During warm-up F disables the bootstrap and uses 'complete observed returns', but retrieved windows end at 0.5, 1, 2 or 3 seconds while the value claims later continuation. A window ending is not an episode ending. Training V on a three-second zero-tail target and then using it as an unlimited tail changes its meaning. Required: state the return horizon and valid target end. One coherent option is horizon-conditioned finite return prediction with observed targets to that horizon and V(S,g,remaining_time), where remaining_time=0 gives zero. Another is continuing-value bootstrapped training with separate acting qualification; its unqualified training target must not masquerade as measured ground truth. A pause/reset must retain the stated truncation treatment. This is a target-definition issue, not a request for a training run.

R2-06 — Root motion and camera-motion compensation need a sensed estimator.
A proposes root pose/velocity in S and says body angles/velocities come from proprioception. Joint angles alone do not measure the translating body's root pose. Current vestibular_sense.py describes gravity/head turning, neck variables, trunk up, support/effort and validity, not a complete observed world-root pose. The stereo tracker must specify its body-relative coordinate frame and how frame-to-frame ego-motion is estimated (for example an explicitly proposed visual/inertial estimator with uncertainty), including the stationary-background assumption/failure. Otherwise apparent object motion during a body shift can be credited as object control by F. Exact simulator root/object coordinates may validate this estimator but must not become hidden acting inputs. Root translation uncertainty must reach tracking and control-effect uncertainty.

R2-07 — The proposed joint head is not yet an identified residual of the old body prior.
E calls every new output a residual and says the old learned prior is preserved. The existing efference.body prior outputs handle position/rotation changes, whereas the new head outputs q/qdot/root changes. Feeding the old prior as an input does not define a baseline in the new output coordinates and does not ensure zero-initialized behavior reuses it. Required: define projection of the nominal predicted handles into a joint/root baseline with explicit failure behavior and add a zero residual there; or label this as a new joint-state predictor conditioned on the old prior, with an explicit pretraining/distillation target. Preserve old weights/moments in either case. Do not imply that retaining old parameters proves their useful prediction has been retained in the new rollout.

R2-08 — The control metric needs a context-dependent estimator and stable response frame.
The linear randomized-effect regression is concrete, but one B fitted across all starting states is not a per-contact control capacity. Grasped, untouched and supported objects can have very different action response matrices. The later sentence 'predict capacity from the current state/contact relationship' leaves the estimator/target join implicit. Required: define local context strata or a conditional B(S), minimum randomized support/rank, actual assignment versus filtered execution, response coordinates corrected for ego-motion, noise/control covariance and the training labels for the capacity predictor. Keep intervention size bounded and log it. Otherwise changing the body/camera or covariance can increase the determinant without gaining control of the object.
