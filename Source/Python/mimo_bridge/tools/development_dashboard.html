                Requested versus actual movement

                Did the body do what each command asked?

                Every command asks the fingers, the wrists and the other body parts to move: to an angle, a direction or a place. For each saved command, in training and in tests, the viewer measures how much of the way there the body got in the command's 250 ms, and can draw it: the body at the start, as the command asked for, and where it got to.

                The middle one: for that body part, half of the commands in these dates ended nearer what was asked for, half farther (all of them, with or without a saved start).

                Test movements tried at each checkpoint

                A checkpoint is a saved copy of the model's learned numbers at one training model step. At each checkpoint, a scheduled check starts each of the 8 bodies from its saved pose and asks for one test movement: close or open the fingers, reach with the left wrist, turn the trunk, or bend the left elbow. Four commands run for 250 ms from the same pose:

                • the motor controller's own command: the starting line (0%);
                • that command with the test change put straight in (orange): where it ends is the test pose;
                • two planner searches (green: direct, blue: synergy): each searches for the command the model predicts ends at the test pose, then runs it.

                Each bar shows how much of the asked-for change a try made beyond the starting line (100% = the whole change). A planner bar as long as the orange bar means the planner reached the test pose.

                    How to read the charts

                    Across: training steps, continuing across restarts. Up: the measurement and units named beside each chart. Gaps mean no reading. Point at a chart, or focus it and use the arrow keys, for a value and date.

                    Lines show averages of available report windows over the step ranges given in their popups. The latest reading above a chart is an individual report and can differ from its final averaged point.

                    Vertical lines mark restarts. A goal line marks a target; a comparison line is the result the model must beat. Each chart defines its scale and any other reference lines.
