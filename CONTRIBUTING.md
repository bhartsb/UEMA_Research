Mind Machine Learning under the Mind Machine Learning Noncommercial License 1.0 only (the file `LICENSE`), which does
not allow the commercial licensing the project needs, so it cannot be included.

Welcome now: issues, questions, experiment reports and reviews. Mind Machine Learning will announce when the agreement
and the merge check are ready.
